ClosetCycle Database Diagram

COMP 3541 Final Project — relational structure used by the PHP/MySQL application.

users

  • PK userID INT
  • firstName VARCHAR(50)
  • lastName VARCHAR(50)
  • email VARCHAR(100) UNIQUE
  • passwordHash VARCHAR(255)
  • role ENUM(member, admin)
  • dateCreated DATETIME
  • isActive TINYINT(1)

categories

  • PK categoryID INT
  • categoryName VARCHAR(60) UNIQUE

occasions

  • PK occasionID INT
  • occasionName VARCHAR(60) UNIQUE

items

  • PK itemID INT
  • FK ownerID → users.userID
  • FK categoryID → categories.categoryID
  • FK occasionID → occasions.occasionID
  • itemName VARCHAR(100)
  • brand VARCHAR(80)
  • size VARCHAR(20)
  • colour VARCHAR(50)
  • itemCondition ENUM
  • description TEXT
  • imageName VARCHAR(255)
  • status ENUM
  • dateAdded DATETIME

borrow_requests

  • PK requestID INT
  • FK itemID → items.itemID
  • FK borrowerID → users.userID
  • neededFrom DATE
  • neededUntil DATE
  • message VARCHAR(500)
  • status ENUM
  • requestDate DATETIME

Relationships

  • One user can own many items.
  • One category can be used by many items.
  • One occasion can be used by many items.
  • One item can receive many borrowing requests.
  • One user can create many borrowing requests as a borrower.
  • Deleting an item cascades to its related borrowing request records.
